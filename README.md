# Anwar / Nhóm 10 — Vanilla HTML, CSS, JavaScript

## Chạy thử
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt. Có thể dùng VS Code + Live Server để trải nghiệm ổn định hơn.
3. Không cần cài React, Tailwind hay build tool.

## Cấu trúc
- `index.html`: khung HTML và nạp stylesheet/script.
- `styles.css`: giao diện responsive, màu sắc, animation, hover và hiệu ứng reveal.
- `script.js`: nội dung hai portfolio, chuyển trang Cá nhân/Nhóm, điều hướng, thanh tiến trình cuộn và form demo.

Lưu ý: form liên hệ hiện chỉ hiển thị thông báo demo ở trình duyệt, chưa gửi dữ liệu tới email/server. Ảnh và Google Fonts được tải từ Internet.
